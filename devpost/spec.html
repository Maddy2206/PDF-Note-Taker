PDF Note taker — Technical Spec

Visual companion. Canonical source: devpost/spec.md. Implements prd.md.

In plain language: a website that runs entirely in your browser. A PDF reader (pdf.js) on the left, an Excalidraw notes canvas on the right. Highlights and clipped diagrams are placed onto the canvas; everything is saved in the browser's own database (IndexedDB). No server, no login.

Architecture

Journey through the system

Components (tap to open)

Dashboardprd: Dashboard cards, Create board and uploadCard grid from IndexedDB; create dialog with PDF-only check; rename; delete with confirm.
Board Workspace Shellprd: Split workspacereact-resizable-panels: draggable divider, close/reopen each pane, saves ratio and visibility; owns autosave.
PDF Viewerprd: Highlight to handwritten notepdf.js canvas + text layer, zoom, saved highlight overlays, banner for text-less (scanned) PDFs.
Selection Popoutprd: Highlight to handwritten noteColor, font, Export to board. Selection stored as page-relative rectangles so it survives zoom and reload.
Diagram Select Toolprd: Diagram importDotted rectangle drag on a page; region re-rendered at high resolution to PNG; imported to notes.
Notes Canvasprd: Notes toolsExcalidraw with full toolbar, lined/blank paper, Download button, driven through its API.
Handwritten Note Elementprd: Highlight to handwritten notePreferred: native Excalidraw text with a custom font if supported. Fallback: image rendered in the font, text kept in customData, double-click to edit.
Next-Free-Spot PlacementNew items go below the lowest existing element, plus a gap, at the left margin.
Storage Layer and PDF Exportprd: Save, resume, downloadOne wrapper module for IndexedDB; export scene to canvas, slice into pages, write PDF with jsPDF.

Where it runs

  • npm install, npm run dev, open localhost:3000.
  • Deploy: push to your GitHub repo, import in Vercel, accept Next.js defaults. No keys. Visitors start with no boards (storage is per browser).
  • Still required for submission: demo video and public repo.

Parallel agent work streams

After a short serial foundation (scaffold, types.ts, storage.ts), four streams can run at once: 1 Dashboard · 2 PDF viewer + popout + diagram tool · 3 Notes canvas + handwritten note + placement + paper · 4 PDF export. Then wire them together serially.

Failure modes and open issues

  • Non-PDF upload: rejected before storing.
  • Scanned PDF: banner; diagram tool still works.
  • Storage full/unavailable: message; works in-session only.
  • Open risk: Excalidraw may not allow custom handwriting fonts. Check first; fallback is the image-based note.
  • Library versions not verified; lined paper tracking pan/zoom to be tested.
